# Vi3W model drop-in folder

Put the exported GLB assets here using these exact filenames:

- `hovercraft.glb`
- `energy-crystal.glb`

The app loads them from `/models/hovercraft.glb` and `/models/energy-crystal.glb`. If they are absent, the built-in procedural meshes are used instead. See `docs/VI3W_ASSET_PROMPTS.md` for copy-ready prompts.
